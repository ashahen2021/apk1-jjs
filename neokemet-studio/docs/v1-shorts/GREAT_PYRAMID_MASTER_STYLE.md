# Great Pyramid as the master visual style for new NeoKemetAI films

The visual standard is the **original The Great Pyramid** project, not
Tomb Painting Flat. Both are supported, but they are separate visual languages.

## Original style ingredients reused in code

- Warm antique paper backdrop and original earth/teal/ochre palette from `engine/src/lib/theme.ts`.
- Hand-etched/roughened large shapes, via `RPoly` and `RRect` instead of flat outlined rectangles.
- Mineral dry-brush texture via `Streaks` and `Stipple`.
- Figure silhouettes, face/profile details and proportions from `Figure` and `GroundShadow`.
- Architectural/environment layers via `Backdrop`; deliberate depth and restrained camera movement.
- `Dust`, `Glow`, `Flame` for atmospheric subjects.
- Original `PrintOverlay` and original **paper-strip `Subtitles`**, NOT Tomb Painting Flat's bold black word band.
- Elegant `Caption` and classic Josefin Sans/Cormorant typography where needed, not large unstyled typography boxes.

## Film-specific SVG production

For each new film, author a subject-specific React/SVG print pack that composes
the original shared drawing objects. Return safe geometric fallback layers for
portability; attach an optional validated `printRecipe` in each ArtShot.

- Implement the print shot in a film-specific file under `engine/src/templates/`.
- Add a recipe identifier to the authored film's artwork pack. **Do not** use
  arbitrary code generated by Ollama. Ollama may propose the shot plan only.
- Connect that recipe to the V1 renderer in an explicit, controlled registry.
- Keep the existing V1 flat theme operational as a separate choice.
- Make the interface render actual Remotion frames **before** approving any art.
  The geometric thumbnails are fallback diagnostics, never the style reference.
- Build 12 actual full-resolution sample shots for Painting the Dark and
  compare with the original Great Pyramid visual benchmark.
- Keep narration/audio/timing unchanged. Do not alter old projects.

## Review gate

Minimum mechanical validation (size/density/duplicates) is necessary but not
sufficient. Manually inspect all shots for the following subjective criteria:

1. Does it **look like the original Great Pyramid print style**, including
   print textures and gentle palette?
2. Does it communicate the precise narration without generic unrelated props?
3. Is the subject large and comfortably framed? Is there purposeful negative space?
4. Is the camera movement subtle and the typography legible?
5. Are characters proportionate and historical details qualified where uncertain?
6. Are shots distinct rather than the same scene with new labels?

Never mark a pack visually approved before those stills have been compared.

## Windows test studio

Use the beta ZIP built by GitHub Actions from this branch. The safe launcher
keeps paid services off. To test explicitly enabled ElevenLabs, use the
optional launcher and a private, rotated API key. The offline print artwork
does not require Ollama or ElevenLabs.
