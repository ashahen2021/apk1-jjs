# Visual Development Lab — نسخة تجريبية مستقلة

## ما الجديد؟
أضفنا تبويب **4 · Visual Lab** إلى نسخة V1 على الفرع `feature/v1-visual-development-lab`.

الغرض: بدل تكرار قالب قديم مع كل شورت جديد، يحلّل التطبيق مشاهد السكريبت ثم يقترح SVG أصليًا ومتحركًا لكل مشهد — ويُعتمد بعد مراجعة المستخدم فقط.

هذا ليس توليدًا فوتوغرافيًا ولا يُضمن رسم أي شيء بدقة مطلقة. الرسوم بسيطة وفق أسلوب V1، وتُراجع قبل النشر.

## خطوات تجربة نظرية المنحدر على Windows
1. حمّل هذا الفرع بصيغة ZIP من GitHub وافتح مجلد `neokemet-studio` **داخل** المستودع.
2. نفذ `npm.cmd ci --no-audit --no-fund` ثم `npm.cmd start`.
3. افتح `http://127.0.0.1:4173`.
4. في مشروع تجريبي جديد، الصق سكريبت 15/30 ثانية وقسّمه إلى فقرات في تبويب Script.
5. فعل `V1 topic-specific illustrated Shorts (beta)` ثم `Build storyboard from script`، أو استورد Production .md مع تفعيل وضع V1.
6. افتح **4 · Visual Lab** واضغط `1 · Analyze script and scenes`.
7. لموضوع منحدر الأهرامات، اضغط `Generate Pyramid Ramp art (offline)`. هذا الاختبار لا يحتاج Ollama أو API مدفوع.
8. راجع معاينة كل لقطة في القسم، ثم اضغط `3 · Approve drawings for this project`.
9. انتقل إلى Storyboard وشغّل `Preview frame` في المشاهد للتحقق من جودة التصيير. بعد ذلك اضغط Save project ثم Export.
10. يمكنك استخدام `Undo art approval` قبل إجراء تغييرات أخرى إذا لم تعجبك الرسومات.

## ماذا عن موضوع غير موجود بالمكتبة؟
افتح Settings وحدد Ollama server/model على حاسوبك ثم ثبت وشغّل نموذجًا محليًا يستطيع إنتاج JSON منضبط. بعد تحليل المشاهد، اختر `Generate new art using local Ollama`.

**هذا خيار محلي اختياري.** إذا لم يكن Ollama مثبتًا، ستظهر رسالة توضح السبب. نموذج الرسم ينتج بيانات SVG آمنة (أشكال وخطوط)، وليس كود JavaScript أو ملف SVG عشوائيًا. قد يفشل إذا لم يلتزم النموذج بالبنية المطلوبة أو قد تكون جودة الرسوم متواضعة؛ حينها لا يغيّر التطبيق المشروع.

## الأمان والاستقرار
- `Analyze` و`Generate` لا يغيران المشروع المحفوظ؛ هما اقتراحان فقط.
- يتم فحص ملف مشروع كامل بعد الضغط على Approve، ثم يُحفظ فقط بعد الضغط على Save.
- يحتفظ كل مشهد بالسكريبت والصوت والمدة؛ يضاف فقط نوع القالب `v1-topic-short` ورسومات `artShots` داخل `project.json`.
- الرسومات الجديدة قابلة للنقل إلى جهاز آخر عند نسخ مجلد المشروع أو ملف `project.json` مع موارده. لا تتم مزامنة المشاريع المحلية تلقائيًا على GitHub.
- لم تتغير مشاريع V3 أو الفيديوهات القديمة.
- قد يتجاوز الفيديو مدة 15/30 ثانية إذا كان الملف الصوتي أطول؛ حماية التعليق الصوتي مستمرة.
- لا توجد مكالمات ElevenLabs أو Fable أو CoArena أثناء تحليل الرسومات أو توليدها محليًا.

## حدود الإصدار الحالي
- رسم المنحدر مدعوم مباشرة ضمن محرّك SVG محلي.
- الموضوعات الجديدة الأخرى تعتمد على Ollama محلي، أو على توسيع مكتبة الأشكال يدويًا.
- الغرض من هذا الإصدار هو إزالة الحاجة إلى كتابة كود جديد **عندما ينجح النموذج المحلي في رسم الأشكال المطلوبة**، وليس الادعاء بأن جميع الموضوعات ستنجح تلقائيًا.
- الصياغة العلمية والحقائق التاريخية وتناسق الحركة تحتاج مراجعة بشرية قبل النشر.
