# NeoKemetAI Animation Studio

A local, standalone generator for 2D animated documentary shorts about ancient Egypt, in a
vintage travel-poster print style. You write (or import) a script, arrange the scenes in a
storyboard, add narration, and export an MP4 — all on your own PC.

- Runs on Windows (also macOS / Linux). No Claude, no cloud rendering, no paid service needed.
- Engine: Remotion + React + TypeScript + SVG. FFmpeg is bundled with Remotion; nothing extra to install.
- Offline narration with Piper. Optional local script/storyboard generation with Ollama.
- Output: 9:16 (1080×1920), 16:9 (1920×1080) or 1:1 (1080×1080), 24–60 fps. Short films or long documentaries: up to 40 scenes of any length.

## Install (Windows)

1. Install **Node.js LTS** (version 18 or newer) from https://nodejs.org.
2. Double-click **`Start-NeoKemetAI-Studio.bat`**.
   The first run installs the studio (internet needed once, a few minutes) and then opens
   http://127.0.0.1:4173 in your browser. Keep the black window open while you work.
3. The first preview or export also downloads a small headless Chrome that Remotion uses to
   draw frames (once, about 100 MB). After that the studio works offline.

Optional, for offline narration — run once in PowerShell from this folder:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup-piper.ps1
```

It downloads Piper and the British English voice `en_GB-alan-medium` into `tools\`. Another
voice: add `-Voice en_US-ryan-high` (any name from the Piper voice list).

On macOS / Linux, start the studio with:

```bash
npm install
```

```bash
npm start
```

## Make a video

The app has five numbered tabs; work left to right.

1. **Project** — title, topic, output format, frame rate, subtitles on/off. The film length is shown here.
2. **Script** — type, paste or import a `.txt` / `.md` script. **Each paragraph is exactly one scene**:
   separate scenes with a blank line. A paragraph is never split, however long, and its full text
   is the narration. Up to 40 paragraphs. Then either
   - **Build storyboard from script** — offline keyword rules choose a template, environment and
     characters for each paragraph; or
   - **Generate storyboard with Ollama** — optional, uses a model running on your PC.
3. **Storyboard** — one card per scene. Choose the visual template, environment, camera move,
   characters and their actions, on-screen label, and edit the narration. *Preview frame* draws a
   still; *Render this scene* exports just that scene. Reorder, duplicate or delete scenes.
4. **Narration & sound** — *Generate narration offline (Piper)* speaks every scene, or import your
   own recording per scene in the storyboard. Choose the built-in score, your own music file, or
   none; switch the generated sound effects on or off; set volumes.
5. **Export** — *Export full MP4*. Progress is shown per scene; the file appears in
   `workspace\output\` with a player and a download link.

**Building a storyboard is safe.** The new storyboard is validated as a whole before it replaces
the old one. If anything is wrong (for example more than 40 paragraphs) you get a message and
the current project stays exactly as it was.

**Timing is automatic.** Scene lengths vary freely — a 36-paragraph script makes a 13–15 minute
film with scenes of 15–30 seconds each. Each scene lasts as long as its narration (half a second of lead,
the measured speech, a short tail), and subtitles are spread across the spoken span. Set
"Length" on a scene only if you want to override that.

**Re-exports are fast.** Every scene is rendered to its own cached clip. Changing one scene
re-renders only that scene; changing music, volumes or narration audio re-renders nothing.

## Visual library

All artwork is hand-built SVG generated by code (no image files except three procedural paper
textures). Everything is seeded, so the same project always renders the same frames.

- **Templates** — title card, landscape, characters, procession, artifact, tomb interior
  (intact / looted), tomb cutaway, coffin chamber, journey map, end card.
- **Royal Cache presets** — the 18 hand-directed shots of the original film, usable as scenes
  in any project. They take no options and stretch to the narration length. They were composed
  for 9:16; in 16:9 the sides of some presets show plain paper.
- **Environments** — Theban cliffs, Deir el-Bahari, Giza pyramids, Nile valley, temple
  courtyard, village, open desert, market street, painted tomb wall.
- **Characters** — priest, pharaoh, noblewoman, scribe, bearer, villager, 19th-century worker
  and two officials; actions: stand, walk, talk, read a papyrus, carry a torch, hold a staff, point.
- **Objects** — royal coffin, papyrus scroll, canopic jars, amulets, seated statue, obelisk,
  treasure chest; plus biers, boats, stalls, columns, palms, houses.
- **Cameras** — push in, pull back, pan left / right, rise, static, all with multiplane parallax.

## Optional local AI (Ollama)

Install Ollama from https://ollama.com, pull a model, and the status pill in the header turns green:

```bash
ollama pull llama3.1
```

Set the model name in **Settings**. The studio sends the model a JSON schema of the scene
format and validates the answer; an invalid answer is sent back once for correction and
otherwise rejected with the reason. AI-written narration is not fact-checked — read it before
you export. Everything else works without Ollama.

## Optional paid service (ElevenLabs)

Off by default and never required. If you enable it in **Settings**, narration text is sent
to ElevenLabs and billed to your account, and the app asks for confirmation each time. The
key is kept only in `workspace/settings.json` on your PC (not committed), or read from the
`ELEVENLABS_API_KEY` environment variable.

## Command line

Everything the app does is also scriptable. The argument is a project folder name under `projects/`.

```bash
npm run validate -- demo-great-pyramid
```

```bash
npm run narrate -- demo-great-pyramid
```

```bash
npm run still -- demo-great-pyramid 3
```

```bash
npm run scene -- demo-great-pyramid 3
```

```bash
npm run render -- demo-great-pyramid --format 16:9
```

```bash
npm test
```

`npm test` checks the bundled projects, schema validation, the offline planner, caption
timing, the Ollama client (against a mock server) and the audio engine.

## Project files

A project is a folder with a `project.json` (validated against `shared/schema.ts`) and its
audio:

```json
{
  "title": "The Great Pyramid",
  "format": "9:16",
  "fps": 30,
  "scenes": [
    {
      "id": "s02",
      "template": "characters",
      "environment": "temple-courtyard",
      "camera": "pan-right",
      "label": "King Khufu",
      "cast": [{ "kind": "scribe", "action": "read" }, { "kind": "pharaoh", "action": "talk" }],
      "narration": "It was built for King Khufu of the Fourth Dynasty…",
      "narrationFile": "narration/02-s02.wav"
    }
  ]
}
```

## Folder map

```
Start-NeoKemetAI-Studio.bat   Windows launcher
ui/                           browser interface (plain HTML / CSS / JS)
server/                       local server, render pipeline, audio engine, TTS, Ollama, CLI
shared/                       scene schema, catalog of templates / characters / environments, timing, planner
engine/src/
  components/                 reusable SVG library: figures, coffins, landscape, environments, objects, camera, print
  templates/                  data-driven scene templates
  presets/royal-cache/        the 18 original Royal Cache shots
  lib/                        palette, seeded noise and rough-print geometry, easing
engine/public/                fonts (SIL OFL) and procedural paper textures
projects/                     your films (one folder each)
scripts/                      Piper setup, texture generator
workspace/                    cache, exports and local settings — created at run time, not committed
tools/                        Piper and voices — installed by the setup script, not committed
```

## Adding to the library

- New environment: add an id to `ENVIRONMENTS` in `shared/catalog.ts` and a `case` in
  `engine/src/components/Environments.tsx`.
- New character: add an id to `CHARACTERS` and its costume in `engine/src/components/Figures.tsx`.
- New template: write a component in `engine/src/templates/`, register it in
  `templates/index.tsx`, and describe which fields it uses in `TEMPLATES`. It appears in the
  storyboard selector and in the Ollama schema automatically.

## Troubleshooting

- **"Port 4173 is already in use"** — the studio is already open in another window; close it, or set `PORT` to another number.
- **"Piper is not installed"** — run `scripts\setup-piper.ps1`, or import your own narration audio per scene.
- **Ollama pill is grey** — Ollama is not running; it is optional.
- **First export is slow to start** — the engine is being bundled and headless Chrome downloaded; this happens once.
- **Export fails on one scene** — the message names the scene; use *Render this scene* to reproduce it.
